#  Django Ticketing System

A simple ticketing system built with Django where users can create, manage, and track tickets (issues/tasks/requests).

---

##  Features

- User registration, login, and logout
- Create, view, edit, and delete tickets
- Filter and sort tickets by status, priority, and date
- Responsive design using Bootstrap
- PostgreSQL database integration
- User roles with Admin panel customization
- Pagination support for ticket lists

---

##  Tech Stack

- Python 3.8+
- Django (latest stable version)
- PostgreSQL
- HTML5, CSS3, Bootstrap 5
- JavaScript (for dynamic frontend interactions)
- Git & GitHub

---

##  Notes
- Make sure PostgreSQL is running before you run the server.
- For production, it is recommended to use environment variables (e.g., .env or django-environ) to securely store sensitive credentials such as the database password.
